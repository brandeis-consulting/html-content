CDS · ANALYTICAL QUERY

    


    

      

        
Slice

        
Eine Dimension wird auf genau ein Mitglied festgelegt, die übrigen bleiben vollständig. Aus dem Würfel wird eine Scheibe, die Dimension verschwindet aus dem Aufriss und wandert in den Berichtskopf.

      

      

        
Dice

        
Mehrere Dimensionen werden auf Teilmengen eingeschränkt. Es entsteht ein kleinerer Teilwürfel mit unveränderter Dimensionalität, im Bericht eine Kombination von Filtern.

      

      

        
Fünf Dimensionen, drei Achsen

        
Ein Würfel lässt sich nur dreidimensional zeichnen, ein Datenwürfel hat beliebig viele Kanten. Die beiden Dimensionen ohne Achse verschwinden nicht, sie werden über ihre aktive Selektion verdichtet. Genau das sind die freien Merkmale einer Query.

      

      

        
Vorsicht bei Quotienten

        
Der Ø Betrag je Abrechnung darf nicht aufsummiert werden. Er entsteht nach der Aggregation aus Summe Betrag durch Summe Abrechnungen, in CDS als berechnete Kennzahl auf Query-Ebene.
